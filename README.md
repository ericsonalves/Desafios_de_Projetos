# 📊 Simulador de Investimentos em Fundos Imobiliários

Projeto desenvolvido como parte de um **desafio de projeto da DIO (Digital Innovation One)**, com o objetivo de colocar em prática conhecimentos de **Excel** na criação de uma planilha para simulação de investimentos em **Fundos Imobiliários (FIIs)**.

## 🎯 Objetivo

Desenvolver uma planilha **interativa, organizada e visualmente limpa**, capaz de auxiliar o usuário na realização de simulações práticas relacionadas a investimentos em Fundos Imobiliários.

A proposta foi aplicar conceitos de Excel para transformar dados e informações financeiras em uma ferramenta simples de utilizar e interpretar.


## 📌 Funcionalidades

A planilha foi desenvolvida para permitir ao usuário realizar simulações de investimentos de forma prática, utilizando informações inseridas na própria ferramenta.

Entre os recursos utilizados estão:

* 📈 Simulação de investimentos;
* 💰 Cálculos financeiros utilizando fórmulas;
* 🔎 Busca e relacionamento de informações com **PROCV**;
* 📊 Cálculos utilizando a função **VF**;
* 🗂️ Organização das informações por meio da renomeação de células;
* 🎨 Interface com formatação limpa e intuitiva;
* 🖱️ Estrutura pensada para facilitar a interação do usuário.

## 🧠 Conceitos praticados

Durante o desenvolvimento do projeto foram colocados em prática conceitos importantes de Excel, incluindo:

**Fórmulas →** automatização dos cálculos da planilha.

**VF →** utilização de conceitos de valor futuro em simulações financeiras.

**PROCV →** pesquisa e recuperação de informações a partir de uma tabela de dados.

**Nomes de células →** organização e facilidade na utilização das fórmulas.

**Formatação →** criação de uma interface visualmente organizada e de fácil compreensão.



## 🚀 Aprendizados

Este projeto contribuiu para o desenvolvimento prático de conhecimentos em **Excel aplicado à análise e simulação financeira**, reforçando a utilização de fórmulas, funções de pesquisa, organização de dados e construção de ferramentas interativas.

Além do conhecimento técnico, o projeto também permitiu trabalhar conceitos de **organização, apresentação de informações e experiência do usuário dentro de uma planilha**.
